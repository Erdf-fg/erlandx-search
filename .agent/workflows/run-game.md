---
description: How to run the Among Digital game
---
To start the game, you need to run both the server and the client.

### 1. Start the Multiplayer Server
// turbo
1. Open a terminal in `server` and run:
`npm start`

### 2. Start the Game Client
// turbo
2. Open another terminal in `client` and run:
`npm run dev`

### 3. Play
3. Open two or more browser tabs at the URL shown in the client terminal (usually `http://localhost:5173`).
4. Enter different names and click **START MISSION**.
5. Once 2 players join, roles will be assigned!
